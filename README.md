# Blinkit Business Analytics & Business Analysis Project

## Project Overview
This is an end-to-end **Business Analyst + Data Analytics portfolio project** based on Blinkit (instant grocery delivery platform).

The project combines **business analysis, data analytics, SQL-based customer analysis, Python data cleaning, and Power BI dashboarding** to identify operational inefficiencies, customer behavior trends, and business growth opportunities.

This project was built to simulate a real-world business analytics engagement.

---

## Business Problem Statement
Blinkit operates in a fast-paced quick-commerce environment where customer retention, delivery performance, inventory management, and marketing efficiency directly impact profitability.

The objective of this project was to analyze business operations, identify key problem areas, and propose data-driven business improvements.

---

## Project Objectives
- Analyze customer purchasing behavior
- Evaluate delivery performance and operational efficiency
- Assess inventory utilization
- Measure marketing campaign effectiveness
- Calculate customer lifetime value (CLV)
- Identify retention improvement opportunities
- Build executive-level KPI dashboards
- Document business requirements and process improvements

## Project Workflow
### 1. Business Analysis
- Identified core business challenges
- Defined business requirements
- Created functional requirements
- Designed process improvement workflows
- Documented user stories and acceptance criteria

### 2. Data Preparation
- Cleaned and transformed raw Blinkit datasets using Python
- Standardized data for analysis
- Removed inconsistencies and duplicates

### 3. SQL Analytics
Performed analytical queries including:
- Customer Lifetime Value (CLV)
- Repeat customer analysis
- Order trends
- Customer segmentation
- Revenue analysis

### 4. Dashboard Development
Built a Power BI dashboard for:
- Revenue KPIs
- Customer metrics
- Delivery performance
- Inventory insights
- Marketing performance
- Operational trends
